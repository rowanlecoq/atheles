# Atheles Email Templates

These are branded HTML email templates for Shopify notifications.

## How to use:
1. Go to Shopify Admin -> Settings -> Notifications
2. Click on the notification you want to update
3. Replace the email body HTML with the contents of the corresponding file
4. Click Save
5. Send a test email to preview

## Templates included:
- `customer-account-invite.html` - When you invite a customer
- `customer-welcome.html` - After account activation
- `customer-password-reset.html` - Password reset request
- `customer-email-change.html` - Email address change confirmation
- `order-confirmation.html` - Order placed
- `shipping-confirmation.html` - Order shipped
- `contact-customer.html` - When you message a customer
